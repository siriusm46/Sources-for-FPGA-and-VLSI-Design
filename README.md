# Sources for FPGA and VLSI Design

Welcome! 👋

This repository is dedicated to anyone passionate about **Digital Hardware Design, FPGA development, and VLSI/ASIC chip design**.

## Purpose

The goal of this repo is simple:

- **Collect** the best learning materials, tools, and tutorials I’ve found useful over the years.  
- **Organize** these resources in one easy-to-navigate place.  
- **Share** knowledge with the community to help everyone learn and build better digital systems.

Whether you're just starting out or looking to deepen your understanding, this repository aims to guide you through the vast world of hardware design and chip development.

## How to Use This Repo

- The detailed list of **resources and links** can be found in [Sources.md](Sources.md).  
- Feel free to explore, learn, and contribute by suggesting new resources or improvements.
